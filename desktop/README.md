# yappy for desktop

A native Rust ([Tauri 2](https://v2.tauri.app)) shell around **app.yappy.gg**.

Deliberately thin: the window loads the deployed web client directly, so the
desktop app has every web feature the moment it ships — no second release
train, no stale bundle, no extra CORS origins (the page's origin stays
`https://app.yappy.gg`, so the API and gateway see an ordinary browser).

## Build

Requires Rust (stable) and Node/pnpm. This package is standalone — it is NOT
part of the repo's pnpm workspace, so always install with:

```bash
pnpm install --ignore-workspace
```

Then:

```bash
pnpm tauri build     # release build + NSIS installer (Windows)
pnpm tauri dev       # live window for development
```

Outputs land in `src-tauri/target/release/` (`yappy.exe`) and
`src-tauri/target/release/bundle/nsis/` (the installer).

## Icon

`icon-src.png` is generated by `node gen-icon.js` (the yappy mark, drawn with
node built-ins); `pnpm tauri icon icon-src.png` fans it out into
`src-tauri/icons/` for every platform.
